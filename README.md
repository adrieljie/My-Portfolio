# Adriel Agustinus Jie — Personal Portfolio

A personal portfolio website designed and developed to showcase my projects, technical skills, experiences, and creative journey as a Computer Science student specializing in Artificial Intelligence.

This portfolio combines modern web development with a nature-inspired visual identity, featuring mountain and stone elements, thoughtful typography, and smooth animations to create an engaging browsing experience.

## Features

- **Custom Visual Identity** — A distinctive design inspired by mountains, stones, and natural landscapes.
- **Scroll Animations** — Smooth transitions and interactive visual elements throughout the website.
- **Project Showcase** — A dedicated space to explore my projects, contributions, and technical implementations.
- **About Me** — An introduction to my background, interests, and professional journey.
- **Responsive Design** — Layouts designed to adapt to different screen sizes.
- **Interactive Experience** — Subtle animations and visual interactions that enhance the user experience.

## Getting Started

To run this project locally:

**1. Clone the repository**

```bash
git clone https://github.com/adrieljie/My-Portfolio.git
```

**2. Navigate to the project directory**

```bash
cd REPOSITORY
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the portfolio.
